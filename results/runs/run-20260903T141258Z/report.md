## 1. 方法

对每条样本执行 `/evaluate` 完整流程（由子代理实现，均遵守同一 skill）：
1. `check_step_symbolic(steps)` 确定性等式校验 → 取 `first_false_step` 与 `needs_llm_review`；
2. 对 `needs_llm_review` 步骤做语义审查（E2 概念误用 / E5 跳步 / E7 幻觉引用），默认成立、举证判错、宁可漏报不可误报；
3. 全局复核（E1 题意误读 / E4 条件遗漏 / E6 循环论证 / E9 答案对但过程不成立，E9 需 ≥2 信号、证据阈值高）；
4. `verdict_record` 落盘。

### 稳定性验证：独立重评（本次核心改动）
上一次 `--n 20` 的稳定性是「同一样本原样重复提交 5 次」得到的伪 1.0，没有测量任何真实方差。
本次按用户要求改为**独立重新评估**：
- 同一 60 样本交给**第二组全新子代理**（与 primary 完全隔离的上下文）重新走完整判断流程；
- re-eval 子代理**只读题干与步骤**，不接收任何 primary verdict，从零推导；
- 两次 verdict 各自独立落盘，server 返回 `n_identical_resubmissions = 0`，证明没有任何记录是复制提交。

## 5. 失败 / 弱点归因

1. **E9 召回仅 0.53（8/15）**：「答案对但过程不成立」是最难类别。两次独立评估在多个样本上对该类**互相矛盾**（如 math-565、olympiad-561、olympiad-892、omnimath-623/647 均出现一判 E9、一判答案错/有效）。根因：E9 依赖「扰动检验 / 步骤删除检验」的严格证据，而子代理在答案恰好正确时倾向于放过，阈值把握不稳定。
2. **T3 误报率 0.5（2/4）**：小样本 + 高难度，对 olympiad 类长链推理的「默认成立」边界判断漂移。
3. **L1（`check_step_symbolic`）区分力仍弱**：自然语言步骤几乎全 `UNKNOWN`；本次 E3 多由子代理在 L3 手工验算发现（gsm8k-40/46、math-72/772、olympiad-249、omnimath-364 等），L1 仅直接抓到其中少数（math-175、math-72、math-772、olympiad-249）。印证 L2/L3 补足 L1 的设计意图，也说明 L1 触发率提升空间有限。
4. **聚合口径的保守性**：`metrics_compute` 对每样本 2 条记录做了聚合（推断为「两判均无效才计为无效」的交集式共识），故 detection/FPR 偏向保守——单趟评估器的真实检出率可能高于 0.806、但误报也可能高于 0.083。建议正式评测时以**单趟**口径复核一次。

## 7. 结论与建议

**四项硬门槛全部通过**（detection 0.806 > 随机；±1 定位 0.75 ≥ 0.5；FPR 0.083 ≤ 0.2；稳定性 0.883 ≥ 0.6），评估器**可用于正式评测**，但必须正视以下已暴露的弱点：

- **E9 召回偏弱（0.53）**：正式评测前建议强化 E9 提示词（扰动/步骤删除检验的强制执行与证据模板），并对 E9 类单独报告召回而非仅整体 FPR。
- **T3 高误报（0.5）**：对 T3/T4 样本做人工抽检兜底（本次 `audit_sheet.csv` 已给出 16 个分歧样本供人工填 `human_verdict`）。
- **稳定性以 0.883 上报，不得回填伪 1.0**：完整 verdict 一致性仅 0.667，正式评测结果应附「独立重评方差」说明。
- **定位以 ±1 为主要口径**（0.75 > 精确 0.611）；T4 精确定位更低，报告时说明。
- 正式评测建议 **n 至少 447（全池）** 或分层各 30+，以获得更紧的 CI（本次 T3 CI 极宽）。
